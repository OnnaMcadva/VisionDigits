Raspberry Pi (малинка) — очень популярный одноплатный компьютер, и у новичков часто возникают вопросы о первом запуске, подключении и настройке, особенно по поводу SSH. Вот подробные шаги:

### 1. Купили Raspberry Pi. Что дальше?

#### 1.1. Необходимые вещи:
- Сама Raspberry Pi (любая модель)
- Карта памяти microSD (обычно от 16 ГБ, класс 10)
- Блок питания (обычно USB-C или microUSB, зависит от модели)
- HDMI-кабель и монитор (для первого запуска, если не хотите сразу через SSH)
- Клавиатура и мышь (для локального управления)
- Интернет-кабель (Ethernet) или Wi-Fi

#### 1.2. Подготовка карты памяти:
1. Скачайте официальный образ Raspberry Pi OS: [raspberrypi.com/software](https://www.raspberrypi.com/software/)
2. Скачайте и установите программу Raspberry Pi Imager (есть для Windows, Mac, Linux).
3. С помощью Imager запишите образ на microSD карту.

#### 1.3. Включение SSH по умолчанию
**По умолчанию SSH на Raspberry Pi выключен из соображений безопасности.**  
Чтобы включить SSH сразу после первой загрузки (без монитора и клавиатуры):

- После записи образа на microSD-карту, вставьте ее обратно в компьютер.
- Откройте раздел `boot` на microSD-карте.
- **Создайте пустой файл с именем `ssh`** (без расширения!) в корне раздела `boot`.
- Если хотите подключиться по Wi-Fi, создайте файл `wpa_supplicant.conf` с настройками Wi-Fi (инструкции можно дать отдельно).

#### 1.4. Первое включение:
- Вставьте microSD в Raspberry Pi.
- Подключите кабель питания.
- Если используете Ethernet, подключите кабель.
- Pi загрузится, подключится к сети, SSH будет включён.

#### 1.5. Поиск IP-адреса Raspberry Pi:
- Можно посмотреть в настройках роутера, какой адрес получил Raspberry Pi.
- Или использовать сканер сети (например, `nmap`, `Advanced IP Scanner`).

#### 1.6. Подключение по SSH:
- В терминале на компьютере (Linux, Mac, или через Putty/Terminal на Windows):
  ```sh
  ssh pi@<ip-адрес>
  ```
  По умолчанию логин: **pi**, пароль: **raspberry**.

---

### 2. Как управлять Raspberry Pi?

- Через SSH (удалённое управление командной строкой)
- Через подключённый монитор/клаву/мышь (как обычный ПК)
- Через VNC (удалённый рабочий стол, нужно включить отдельно)

---

### Краткий ответ:
- **По умолчанию SSH выключен.**
- Для включения SSH создайте пустой файл `ssh` в корне microSD-карты после записи образа.
- Подключите Pi к питанию и сети, найдите IP, подключайтесь по SSH (`ssh pi@ip`).
